# PharmaOneBD releases

Installer builds for the PharmaOneBD Android app. The app checks this repository for updates.

## Website

The repository root hosts the [PharmaOneBD landing page](https://shamimsdp.github.io/PharmaOneBD-releases/) on GitHub Pages. It is a static HTML, CSS, and JavaScript site. Edit `index.html`, `style.css`, and `script.js` to update it; Pages publishes from the `master` branch root.

The page links to this repository's [Releases](https://github.com/shamimsdp/PharmaOneBD-releases/releases) for app builds. Illustrative interface previews are presentation graphics, not screenshots of a current build.
